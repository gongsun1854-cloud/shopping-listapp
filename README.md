# 쇼핑 리스트 앱 🛒

간단하고 사용하기 쉬운 쇼핑 리스트 웹 애플리케이션입니다.

## 기능

- ✅ 쇼핑 아이템 추가
- ✅ 아이템 완료 체크
- ✅ 아이템 삭제
- ✅ 완료된 아이템 시각적 구분
- ✅ 통계 (전체, 완료, 남은 것)
- ✅ 로컬 스토리지에 데이터 자동 저장

## 사용 방법

1. `index.html` 파일을 브라우저에서 열어주세요.
2. 입력 필드에 쇼핑 아이템을 입력합니다.
3. "추가" 버튼을 클릭하거나 Enter 키를 눌러 아이템을 추가합니다.
4. 체크박스로 아이템의 완료 상태를 변경할 수 있습니다.
5. "삭제" 버튼으로 불필요한 아이템을 제거합니다.

## 특징

- 반응형 디자인으로 모바일, 태블릿, 데스크톱에서 완벽하게 작동
- 로컬 스토리지를 사용하여 페이지를 새로고침해도 데이터 유지
- 아름다운 그라디언트 배경과 직관적인 UI
- 완료된 항목은 취소선으로 표시

## 기술 스택

- HTML5
- CSS3
- JavaScript (Vanilla)
- LocalStorage API
